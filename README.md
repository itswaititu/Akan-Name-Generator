# Akan Name Generator

Author: Nathan Waititu

## Description

Akan Name Generator is a simple web application that assigns an Akan name based on a user's date of birth and gender. The project provides an easy way to learn and explore Akan naming traditions.

## Project setup

1. Clone the repository:
   ```bash
   git clone https://github.com/nathan/Akan-Name-Generator.git
   ```
2. Change into the project directory:
   ```bash
   cd Akan-Name-Generator
   ```
3. Open `index.html` in a web browser or serve the folder using a local development server.
